# Ethercat_Slave_Axis_Interface

Repositorio para el código fuente y aplicaciones del interfaz de esclavo EtherCAT.

Estructura principal:
- `applications/` — aplicaciones PlatformIO y demos
- `firmware/` — código de firmware

Instrucciones:
1. Este repositorio contiene varios proyectos PlatformIO. Usa `platformio run` desde cada aplicación.
2. Añade un remoto (GitHub/GitLab) si quieres copia de seguridad y colaboración.

Contacto: mantén los cambios en ramas y abre PRs para integrarlos.
